# Security Policy

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии.

## Сообщение об уязвимости

Не публикуйте токены, приватные репозитории и воспроизводящие данные в открытом issue.
Используйте приватный раздел **Security → Advisories → New draft security advisory** в
GitHub-репозитории проекта.

В сообщении укажите затронутую версию, минимальный сценарий воспроизведения, ожидаемое
поведение и возможные последствия. Получение отчёта будет подтверждено после ручной
проверки владельцем репозитория.
