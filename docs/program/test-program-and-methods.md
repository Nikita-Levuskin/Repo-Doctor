# Программа и методика испытаний

## Объект и цель

Объект — Repo Doctor 1.0.0. Цель — подтвердить функции и инварианты безопасности.

## Средства

Python 3.12.13, pytest 8.4.2, pytest-cov 6.3.0, Ruff 0.16.5, mypy 1.20.2, build 1.6.0.
HTTP проверяется `httpx.MockTransport`; реальные GitHub/GitLab аккаунты не используются.

## Порядок

1. Создать чистое виртуальное окружение и установить `.[dev]`.
2. Выполнить Ruff и mypy.
3. Выполнить pytest с branch coverage и порогом 80%.
4. Собрать sdist/wheel.
5. Установить wheel в новое окружение и проверить версию.
6. На копии демонстрационного репозитория выполнить scan, dry-run, apply, scan и второй apply.

## Критерии

Все процессы завершаются кодом 0, кроме специально проверяемого `check` с ошибками.
После исправления нарушений нет, повторный apply возвращает `[]`. Значения токенов не
попадают в сообщения. Подробная трассировка — `docs/test-plan.md`.
