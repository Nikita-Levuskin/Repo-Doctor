# Руководство пользователя

## Назначение и установка

Repo Doctor проверяет служебные файлы репозитория. Установите Python 3.12, создайте venv и
выполните `python -m pip install .`.

## Команды

`repo-doctor scan PATH` — отчёт; `--format json` включает JSON.

`repo-doctor check PATH` — вариант для CI с кодом 1 при error.

`repo-doctor fix PATH --dry-run` — безопасный предпросмотр.

`repo-doctor fix PATH --apply` — создание отсутствующих файлов. `--overwrite` применяйте
только после резервной копии и просмотра плана.

`repo-doctor config validate FILE` — проверка YAML/JSON.

`repo-doctor pr ... --dry-run` — показать API-запрос. Реальный `--apply` требует токена из
`GITHUB_TOKEN` или `GITLAB_TOKEN` и уже опубликованной исходной ветки.

## Типовые ошибки

Код 2 означает проблему аргумента, пути или конфигурации. Код 3 означает отказ/сбой API.
При 401 проверьте токен; при 403 — права; при 404 — owner/repository; при 409 — состояние
веток; при 429 — дождитесь снятия лимита. Токен в обращение поддержки не прикладывайте.
