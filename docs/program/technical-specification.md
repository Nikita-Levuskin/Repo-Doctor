# Техническое задание

## 1. Введение

Наименование: CLI-утилита «Repo Doctor». Основание: тема курсового проекта. Организация-
заказчик и документ индивидуального задания: ТРЕБУЕТ УТОЧНЕНИЯ.

## 2. Назначение

Программа предназначена для локального аудита структуры программных репозиториев,
безопасной генерации недостающих служебных файлов и подготовки запроса создания PR/MR.

## 3. Требования к программе

Функции и критерии перечислены в `docs/requirements.md`. Интерфейс обязан поддерживать
`scan`, `check`, `fix`, `pr`, `config validate`, `--help`, `--version`. По умолчанию
состояние репозитория не изменяется. Токены поступают только через окружение.

Среда: Python 3.12; Windows, Linux или macOS. Входные данные: путь и необязательная
YAML/JSON-конфигурация. Выходные данные: терминальный или JSON-отчёт, план/результат
исправлений, ответ API провайдера.

## 4. Требования к документации

README, описание программы, программа и методика испытаний, руководство программиста,
руководство пользователя и протокол испытаний. Окончательный состав требует методички.

## 5. Стадии разработки

Анализ требований; проектирование; реализация; unit/integration-тестирование; сборка;
демонстрация; документация; приёмка.

## 6. Порядок контроля и приёмки

Приёмка выполняется командами из `docs/verification-report.md`. Критерии: 39 тестов,
Ruff и mypy без ошибок, покрытие не ниже 80%, успешная сборка и чистая установка,
идемпотентный повторный запуск.
