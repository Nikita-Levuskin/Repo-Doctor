# Описание программы

## Общие сведения

Repo Doctor 1.0.0 — локальный Python-пакет с консольной точкой входа `repo-doctor`.

## Функциональное назначение

Программа стандартизирует минимальную структуру репозитория, не пытаясь менять исходный
код проекта. Выявленные нарушения представлены моделью `Violation`; полный результат —
`AuditReport`.

## Логическая структура

- `cli.py` — команды, режимы и коды завершения;
- `config.py`, `models.py` — валидация входных данных;
- `scanner.py`, `rules.py` — оркестрация и восемь правил;
- `fixer.py`, `templates.py` — безопасные исправления;
- `reporting.py` — текст/JSON;
- `providers.py` — абстракция и адаптеры GitHub/GitLab.

## Входные и выходные данные

Пути обрабатываются `pathlib`. Текст читается только в пределах `max_file_size`, после
отбрасывания NUL-содержащих бинарных данных. Конфигурация проходит строгую Pydantic-
валидацию. Отчёт JSON соответствует полям модели.

## Вызов и загрузка

После установки wheel вызывается команда `repo-doctor`. Внутреннее API доступно через
`scan_repository`, `apply_fixes`, `GitHubProvider` и `GitLabProvider`.
